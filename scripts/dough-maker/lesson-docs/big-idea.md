# The Big Idea

This file covers the Big Idea, the last stop of every lesson. It comes after Burnt Cookies.

- **Papa Dorin's big idea for the passage.** About 3 short paragraphs, each 3 to 4 sentences.
- No em dashes or en dashes.
- **The lesson, not the story.** It says what the passage teaches and why it matters to the baker. It doesn't walk through the events again, since the walkthrough already did that. It names only the moments the lesson needs.
- **Papa Dorin, fully himself.** papa-dorin.md covers how he sounds.
- **Not quizzed.**
- It covers the whole passage, including any included parable or sermon. It brings in anything from the passage the lesson needs for context.
- **No formula.** Each Big Idea is shaped by its own passage, not by a template.

## Output

A JSON file for the passage. Each paragraph is one entry.

```json
{
  "paragraphs": [ "...", "...", "..." ]
}
```
