# The Big Idea

This file covers the Big Idea, the last stop of every lesson. It comes after Burnt Cookies.

- **Papa Dorin's summary of the passage,** about 5 to 7 lines.
- **A real summary** of what the passage means, not a retelling of the verses.
- **Papa Dorin, fully himself.** papa-dorin.md covers how he sounds.
- **Not quizzed.**
- It covers the whole passage, including any included parable or sermon. It brings in anything from the passage the summary needs for context.
- **No formula.** Each Big Idea is shaped by its own passage, not by a template.

## Output

A JSON file for the passage. Each line is one entry.

```json
{
  "lines": [ "...", "...", "...", "...", "..." ]
}
```
